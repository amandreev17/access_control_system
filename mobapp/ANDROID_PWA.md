# Быстрая установка на Android как PWA

## Что уже подготовлено

✅ PWA манифест (`public/manifest.json`)
✅ Service Worker для офлайн-работы (`src/index.js`)
✅ Иконки приложения (`public/logo192.png`, `public/logo512.png`)
✅ Мета-теги для PWA (`public/index.html`)
✅ Лаунчер для запуска всего (`serve.js`; также `./serve.sh` или `npm run serve`)
✅ Поддержка локального IP в API (`src/api.js`)

## Как установить (3 шага)

### 1. Запустите бэкенд

```bash
cd backend
go run main.go
```

### 2. Соберите и запустите фронтенд

```bash
# В другом терминале
npm run build
npm run serve
```

Сервер автоматически определит ваш IP и покажет адрес для Android.

### 3. Установите на Android

1. Откройте Chrome на Android
2. Перейдите по адресу `http://ВАШ_IP:3000`
3. Меню → **«Добавить на главный экран»**
4. Готово!

## Преимущества

- ✅ Не нужен домен
- ✅ Не нужен HTTPS
- ✅ Не нужна сборка APK
- ✅ Работает по локальной сети
- ✅ Офлайн-режим (кэшируется)
- ✅ Автоматические обновления

## Требования

- Mac и Android в одной Wi-Fi сети
- Бэкенд запущен на порту 8080
- Файрвол macOS разрешает входящие соединения
