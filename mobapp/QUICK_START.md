# Быстрый старт: Установка на Android как приложение

## Что нужно сделать

### 1. Запустите приложение

```bash
npm run serve      # то же самое, что ./serve.sh или node serve.js
```

Лаунчер (`serve.js` на Node.js) автоматически:
- Определит локальный IP компьютера
- Соберёт фронтенд, если `build/` отсутствует или исходники в `src/` новее
- Сгенерирует HTTPS-сертификат — **на чистом Node.js, без openssl** (папка `certs/`)
- Соберёт Go-бэкенд, если бинарника нет или исходники новее (папка `backend/`)
- Запустит Go-бэкенд на порту 8080
- Запустит HTTPS-сервер на порту 3443 (PWA + проксирует `/api/*` на бэкенд)
- Запустит HTTP-сервер на порту 3000 (только `ca.crt` — для установки сертификата на телефон)
- Покажет адрес для Android

Нужны только **Node.js 16+** и **Go 1.21+**. Bash, Python и openssl не требуются, поэтому
запуск одинаково работает на macOS, Linux и **Windows (в том числе без WSL)**.

Отдельный терминал для бэкенда не нужен — всё запускается одной командой.
Остановка всего сразу — `Ctrl+C` в том же терминале.

### 2. Установите сертификат на телефон (один раз)

**Без этого шага Chrome НЕ даёт установить приложение** (ошибка «приложение нельзя установить»).

1. В браузере телефона откройте: `http://<IP_Mac>:3000/ca.crt` — файл скачается
2. Настройки Android → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС
3. Выберите `ca.crt`, задайте имя `SKUD`, подтвердите (может потребоваться PIN экрана)
4. Полностью закройте Chrome (смахните из недавних) и откройте заново

### 3. Установите приложение

1. Откройте **Chrome** на Android
2. Введите адрес из терминала (например, `https://192.168.1.42:3443`)
3. Войдите (admin / admin123)
4. Меню (⋮) → **«Установить приложение»** (или «Добавить на главный экран»)
5. Подтвердите

## Готово!

Ярлык приложения появится на главном экране Android **без иконки браузера**.
Запуск — в полноэкранном standalone-режиме, как у нативного приложения.

## Как пользоваться

1. **Вход**: используйте тестовые учетные данные
   - admin / admin123
   - user1 / user123
   - user2 / user123

2. **QR-код**: автоматически обновляется каждые 30 секунд

3. **Сканирование**: считыватель СКУД сканирует QR-код и отправляет токен на `/api/validate-qr`

## Важные моменты

⚠️ **Mac и Android должны быть в одной Wi-Fi сети**

⚠️ **Предупреждение о сертификате** — это нормально: сертификат самоподписанный. Нажмите «Дополнительные → Перейти на сайт».

⚠️ **Файрвол macOS**: разрешите входящие соединения (System Settings → Network → Firewall)

## Обновление приложения

После изменений в коде:

```bash
# Остановите сервер (Ctrl+C)
npm run build      # пересобрать фронтенд
npm run serve      # запустить всё снова
```

Бэкенд (Go) пересобирается автоматически при старте, если его исходники новее бинарника —
для него отдельные действия не нужны. Фронтенд собирается только командой `npm run build`.

На Android обновите страницу (потяните вниз) или переустановите ярлык.

## Запуск на Windows (без WSL)

1. Установите обычными установщиками: [Node.js LTS](https://nodejs.org/) и [Go](https://go.dev/dl/)
2. Один раз в папке проекта: `npm install --legacy-peer-deps`
3. Запустите: `npm run serve` (или `node serve.js`)
4. При первом старте Windows спросит про брандмауэр — разрешите Node.js для **частных сетей** (порты 3443 и 3000)

Сертификаты генерирует сам Node.js, а бэкенд использует чисто-Go драйвер SQLite —
поэтому C-компилятор (MinGW), Python и WSL не нужны.

## Возможные проблемы

**Не открывается на Android:**
- Проверьте, что Mac и Android в одной сети
- Проверьте бэкенд: `curl http://localhost:8080/api/public-key`
- Проверьте HTTPS-сервер: `curl -k https://localhost:3443/`
- Проверьте файрвол macOS (порты 3443, 8080 и 3000)

**Ошибка подключения к API:**
- Убедитесь, что `npm run serve` запущен (он стартует бэкенд автоматически)
- Логи: `logs/backend.log` (HTTPS-сервер — `logs/https_server.log`, сервер сертификата — `logs/ca_server.log`)

**PWA не обновляется:**
- Остановите сервер, выполните `npm run build`, запустите `npm run serve`
- Обновите страницу в Chrome

## Технические детали

- **Frontend**: React 17 (PWA), раздаётся по HTTPS (порт 3443)
- **Backend**: Go + Gin + SQLite (порт 8080)
- **HTTPS**: самоподписанный сертификат, генерируется лаунчером на чистом Node.js (без openssl), прокси `/api/*` → бэкенд
- **Криптография**: подпись QR-кодов ECDSA P-256 (короткая подпись → компактный, легко считываемый QR); RSA-2048 проверяется для QR прежнего формата
- **Сеть**: работает по локальному IP, без домена
