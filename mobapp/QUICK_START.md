# Быстрый старт: Установка на Android как PWA

## Что нужно сделать

### 1. Запустите бэкенд

```bash
cd backend
go run main.go
```

Оставьте этот терминал открытым.

### 2. Запустите фронтенд (в новом терминале)

```bash
npm run serve
```

Скрипт автоматически:
- Определит IP вашего Mac в локальной сети
- Запустит статический сервер на порту 3000
- Покажет адрес для открытия на Android

### 3. Установите на Android

1. Откройте **Chrome** на Android
2. Введите адрес, показанный в терминале (например, `http://192.168.1.42:3000`)
3. Дождитесь загрузки страницы входа
4. Нажмите меню (⋮) → **«Добавить на главный экран»**
5. Подтвердите

## Готово!

Приложение установится как обычное приложение на главном экране Android.

## Как пользоваться

1. **Вход**: используйте тестовые учетные данные
   - admin / admin123
   - user1 / user123
   - user2 / user123

2. **QR-код**: автоматически обновляется каждые 10 секунд

3. **Сканирование**: считыватель СКУД сканирует QR-код и отправляет токен на `/api/validate-qr`

## Важные моменты

⚠️ **Mac и Android должны быть в одной Wi-Fi сети**

⚠️ **Бэкенд должен быть запущен** (порт 8080)

⚠️ **Файрвол macOS**: разрешите входящие соединения (System Settings → Network → Firewall)

## Обновление приложения

После изменений в коде:

```bash
# Остановите сервер (Ctrl+C)
npm run build
npm run serve
```

На Android откройте Chrome, перейдите по тому же адресу, PWA обновится.

## Возможные проблемы

**Не открывается на Android:**
- Проверьте, что Mac и Android в одной сети
- Проверьте, что бэкенд запущен: `curl http://localhost:8080/api/public-key`
- Проверьте файрвол macOS

**Ошибка подключения к API:**
- Убедитесь, что бэкенд запущен на порту 8080
- Проверьте, что IP адрес правильный (см. в терминале после запуска `npm run serve`)

**PWA не обновляется:**
- Остановите сервер
- Выполните `npm run build` снова
- Запустите `npm run serve`
- На Android обновите страницу в Chrome

## Технические детали

- **Frontend**: React 17 (PWA)
- **Backend**: Go + Gin + SQLite
- **Криптография**: RSA-2048 подпись QR-кодов
- **Сеть**: работает по локальному IP, без домена и HTTPS
