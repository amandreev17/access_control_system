# Установка на Android как PWA (без домена)

Быстрый старт для установки приложения на Android через PWA.

## За 3 шага

### 1. Запустите бэкенд

```bash
cd backend
go run main.go
```

Бэкенд работает на порту 8080.

### 2. Соберите и запустите фронтенд

```bash
# В другом терминале
npm run build
npm run serve
```

Сервер покажет адрес для доступа, например: `http://192.168.1.42:3000`

### 3. Установите на Android

1. Откройте Chrome на Android
2. Перейдите по адресу из терминала (например, `http://192.168.1.42:3000`)
3. Меню Chrome → **«Добавить на главный экран»**
4. Готово!

## Важно

- Mac и Android должны быть в **одной Wi-Fi сети**
- Бэкенд должен быть запущен
- Порт 3000 должен быть доступен (файрвол macOS должен разрешать входящие соединения)

## Определение IP адреса Mac

```bash
ipconfig getifaddr en0
```

## Переустановка после обновлений

```bash
npm run build
npm run serve
```

На Android откройте Chrome, перейдите по тому же адресу, PWA обновится автоматически.
