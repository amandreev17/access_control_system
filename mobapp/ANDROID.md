# Установка на Android как PWA

Быстрая инструкция по установке приложения на Android без домена и HTTPS.

## Шаг 1: Запустите бэкенд

```bash
cd backend
go run main.go
```

Бэкенд работает на порту 8080.

## Шаг 2: Запустите фронтенд

```bash
npm run build
npm run serve
```

Скрипт покажет адрес, например:
```
http://192.168.0.126:3000
```

## Шаг 3: Установите на Android

1. Откройте **Chrome** на Android
2. Перейдите по адресу `http://ВАШ_IP:3000`
3. Меню Chrome → **«Добавить на главный экран»**
4. Готово!

## Важно

- Mac и Android должны быть в **одной Wi-Fi сети**
- Бэкенд должен быть запущен на порту 8080
- Используйте **Chrome** (не Яндекс.Браузер)

## Если не работает

### Не открывается на Android
```bash
# Проверьте IP Mac
ipconfig getifaddr en0

# Проверьте что бэкенд работает
curl http://localhost:8080/api/public-key

# Проверьте файрвол
# Системные настройки → Сеть → Файрвол
```

### Ошибка подключения к API
- Убедитесь что бэкенд запущен
- Проверьте что API_URL в коде указывает на правильный IP

### PWA не добавляется
- Используйте режим инкогнито
- Очистите кэш Chrome
- Попробуйте другой браузер (Chrome Canary)
